# AppWorld: A Controllable World of Apps and People for Benchmarking Interactive Coding Agents

Independent audit on 19 November 2026 • 2407.18901v1 · [Paper record](../../sources/arxiv-2407.18901.md)

Sections 1–2. Controlling the state of the applications, people, database and clock allows tasks to be replayed from different initial states. Final-state tests also check for side effects. Section 3 and Tables 1–2 describe 250 scenarios with three variants each, giving 750 tasks split into groups of 105, 60, 168 and 417. The hard set includes tasks requiring Gmail or Amazon, which were unseen during training. Section 4, Table 3. ReAct with GPT-4o passed 48.8% of standard tasks and 30.2% of hard tasks, a drop of 18.6 percentage points. These rates correspond to approximately 82/168 and 126/417 tasks. A scenario requires success on all three variants, yielding scenario pass rates of 32.1% and 13.0%, respectively. These figures apply to the specific model and method. Sections 5–8 compare interactive environments and discuss API limitations, synthetic data and possible applications.
