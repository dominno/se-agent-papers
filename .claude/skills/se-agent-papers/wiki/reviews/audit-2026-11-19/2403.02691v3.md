# InjecAgent: Benchmarking Indirect Prompt Injections in Tool-Integrated Large Language Model Agents

Review of version `2403.02691v3` • 19 November 2026 • 36 pages. [arXiv record](https://arxiv.org/abs/2403.02691v3) · [Metadata and license](../../raw/metadata/2403.02691.metadata.json) · [Paper record](../../sources/arxiv-2403.02691.md)

## Sections and Appendices

- §§1–2, Figure 1 and Tables 1–2. The study measures whether an agent can distinguish an authorized user instruction from untrusted content read from an external source. The dataset combines 17 user scenarios with 62 cases involving an authorization boundary violation. The evaluation uses simulated scenarios and manually reviewed data. - §3. ASR-valid measures the violation rate among agent responses that can be evaluated. ASR-all also includes responses with invalid formats. Table 3 reports the main result for systems whose valid-response rate exceeds 50%. The evaluation distinguishes accepting an unauthorized instruction from producing a well-formed response. ## Independent verification

Each variant has 17 × (30 + 32) = 1,054 cases. In the base setting with GPT-4 and ReAct, the measured rate is 23.6% among valid responses (Table 3) and 23.3% among all responses (Table 8). Table 6 gives a 98.8% validity rate, and 0.236 × 0.988 = 0.2332, or 23.3% after rounding.
