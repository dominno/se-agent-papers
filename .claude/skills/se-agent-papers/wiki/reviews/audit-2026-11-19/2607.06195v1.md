## Quality tests, limitations and final materials

Table 6 distinguishes code coverage from successive stages of bug filtering. Multiple failing tests can reveal the same defect. Table 7 examines classification on 1,000 failing tests containing 28 actual bugs. Agentic Oracle averages 91.17% precision, 72.14% recall and 80.49% F1. Recall falls to 60.65% on another 31 previously known cases.
