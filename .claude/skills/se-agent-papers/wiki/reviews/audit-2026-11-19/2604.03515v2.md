## Independent verification

Table 1 lists nine Python implementations, three TypeScript implementations, and one Rust/TypeScript implementation. The author's claim that “10 of 13” use Python in the limitations section conflicts with this table. The audit checked Codex CLI documentation at revision 9dba7337f2, as identified in Table 15. It describes the native program as implemented in Rust. [PDF, p. 7](https://arxiv.org/pdf/2604.03515v2#page=7) [PDF, p. 35](https://arxiv.org/pdf/2604.03515v2#page=35) [PDF, p. 42](https://arxiv.org/pdf/2604.03515v2#page=42) [Primary documentation at the pinned commit](https://github.com/openai/codex/blob/9dba7337f2/codex-rs/README.md)

The finding that 11 of 13 combine mechanisms concerns the source code of the projects studied. The main-loop category in Table 2 can obscure nested behavior. For example, Aider combines a user-driven loop with automatic correction attempts.
