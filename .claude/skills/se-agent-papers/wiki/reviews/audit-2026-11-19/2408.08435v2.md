## Sections 1–3. What is searched

The authors distinguish the design space, search algorithm, and evaluation function. A meta-agent generates agent code from an archive of previous solutions and validation outcomes. Repair after an execution error and reflection on a solution’s novelty do not guarantee progress in the next iteration. ## Section 4. Tasks, tables and transfer

ARC uses grids up to 5 × 5, with 20 validation tasks and 60 test tasks each evaluated five times. Repetitions cover the same questions. In the other domains search ran for 30 iterations each. DROP was scored by F1 and MGSM, MMLU and GPQA by accuracy. Table 1 and Figure 3 cover different populations. In Table 1 the DROP gain over the strongest manual agent is 79.4 − 65.8 = 13.6 F1 points, and over prompt optimization it is 79.4 − 69.1 = 10.3 points. [PDF, p. 6](https://arxiv.org/pdf/2408.08435v2#page=6) [PDF, p. 7](https://arxiv.org/pdf/2408.08435v2#page=7)

Table 2 covers three designs selected on MGSM. On transfer to GSM8K the best scored 69.5%, versus 43.6% for the manual baseline, a gain of 25.9 percentage points. With Claude-Sonnet as executor, Dynamic Memory leads in Table 3 at 48.3 ± 5.7%, versus 39.3 ± 5.5% for the strongest manual design. The authors give 95% bootstrap intervals. Some individual designs underperform the strongest manual agent after transfer. [PDF, p. 8](https://arxiv.org/pdf/2408.08435v2#page=8) [PDF, p. 9](https://arxiv.org/pdf/2408.08435v2#page=9)

## Sections 5–6 and Appendices A–J

Compared with selecting a prompt or graph, the program can change the computation itself. The discussion covers evaluation cost, safe execution, and the restriction to tasks with a single answer. Appendix A, Tables 4–5, extends transfer comparisons beyond the main tasks. Appendices B–C document meta-agent instructions, error recovery, and the program interface. Appendix D gives a grid representation and an example ARC program. Appendices E–F specify differing numbers of repetitions and how the baselines were implemented. ## Independent source check

The audit distinguishes the model that writes programs from the model that executes the proposed agents. In Table 1 the best manual baselines are Role Assignment on DROP (65.8 F1) and LLM Debate on MGSM (39.0%). The gains are 13.6 F1 points and 14.4 percentage points, respectively. The caption reports 95% bootstrap intervals. The easy ARC subset limits both grid dimensions to five cells. Table 3 compares other executors. The discussion limits the scope to single-step question answering.
