## Review of sections and appendix

- Sections 1–3 and Table 1. The paper combines a historical analysis of several projects with a controlled test of one. The 50 Verified tasks include 20 easy, 25 medium, five difficult and zero very difficult tasks. Eight tasks were excluded because the environment failed even with the reference patch. - §5 (RQ1) and Figures 6–8. The authors ran Qwen Code versions v0.0.10 through v0.10.3 with Qwen3-Next-80B-A3B-Instruct. The mean resolution rate was 30.5% (range 23.0–39.0%), with no clear monotonic improvement (ρ = 0.208, p = 0.231). Token cost showed a stronger trend (ρ = 0.751, p < 0.0001). Two runs per configuration yielded 35 × 50 × 2 = 3,500 attempts. - Sections 6–7, Tables 6–11 and Figures 9–12. At project level, the analysis examines the size and nature of changes between releases. At component level, it relates individual changes to metrics while controlling for the amount of code modified. Changes to the model provider, persistence layer and interface are associated with different metrics. Attributing a change to a pull request is an observational judgment.
