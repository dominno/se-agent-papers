# Assessing Automated Prompt Injection Attacks in Agentic Environments

Review of version `2606.10525v1` • 19 November 2026 • 17 pages. [arXiv record](https://arxiv.org/abs/2606.10525v1) · [Metadata and license](../../raw/metadata/2606.10525.metadata.json) · [Paper record](../../sources/arxiv-2606.10525.md)

## Sections and evidence

- **1–4.** The authors distinguish between performing undesirable actions in the tool environment and returning an undesirable text response. The threat model assumes untrusted content coming from the tool. AgentDojo provides a controlled environment that allows you to observe the actual effect. - **5–6.** The evaluation comprises 20 task pairs in each of four domains, 80 pairs in total. The authors distinguish the event rate in individual runs, the rate of at least one event across repeated attempts and success on the authorized task. A deterministic environment test determines the final action outcome. The auxiliary LLM judge that assesses the first response can be unreliable. The discussion and ethics appendix describe the controlled research setting. ## Independent verification

The confusion matrix in Figure 7 contains 307 true positives, 335 false positives, zero false negatives and 516 true negatives. This yields accuracy of 823/1158 = **71,1%**, precision 307/642 = **47,8%** and sensitivity 307/307 = **100%**. The environment check is independent of the judge’s verdict. The previous wording could imply that a language-model judge determines the final success measure.
