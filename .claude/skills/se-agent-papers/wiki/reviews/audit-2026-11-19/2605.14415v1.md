## Sections, Tables and Appendices

- Sections 1–3, Figure 1 and Tables 1–2. DecompSynth matches repository changes to release notes and then builds a specification. At each stage, the agent starts from its own previous version of the code. The evaluation counts newly required behaviors separately from regressions on previously passing tests. Build+Fix permits one repair using feedback. ## Independent verification

In Table 3, the change for Opus 4.7 raises resolving by 60.8 − 58.3 = 2.5 points and precision by 80.6 − 67.4 = 13.2 points. The equation on p. 5 defines resolving as the proportion of update-related tests that pass. The 60.8% therefore measures tests passed, and cannot be read as the proportion of requirements resolved. The final test suite result of 91.9% uses a different denominator.
