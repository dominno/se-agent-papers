# Reflexion: Language Agents with Verbal Reinforcement Learning

## Sections, tables and examples

- §§1–3 and Algorithm 1. An actor takes actions, a separate evaluator assesses the attempt, and the model writes an analysis of the error to a limited episodic memory. The next attempt uses this record without updating model weights. Feedback can come from the environment, a heuristic or a generated test. - §§4.1–4.2. On ALFWorld, ReAct with reflection and a heuristic completed 130/134 tasks cumulatively across attempts. On HotpotQA, correctness feedback came from comparison with the reference answer. Memory ablations distinguish access to the history from verbal analysis of it. These measurements are cumulative. [PDF, p. 5](https://arxiv.org/pdf/2303.11366v4#page=5) [PDF, p. 6](https://arxiv.org/pdf/2303.11366v4#page=6) [PDF, p. 7](https://arxiv.org/pdf/2303.11366v4#page=7)
- Section 4.3, Tables 1–3. For programming, a single final program was evaluated on hidden tests after up to six self-generated tests. Results varied by language and dataset. On 50 difficult HumanEval Rust tasks, omitting tests yielded 52%, omitting reflection yielded 60%, and combining tests and reflection yielded 68%. Incorrect self-generated tests can accept faulty code or trigger unnecessary changes to correct code. [PDF, p. 7](https://arxiv.org/pdf/2303.11366v4#page=7) [PDF, p. 8](https://arxiv.org/pdf/2303.11366v4#page=8)
- §§5–8. Limitations include local optima, errors in self-assessment and difficulties verifying functions that depend on hardware, services or nondeterminism. The authors discuss broader applications, conclusions and access to the implementation. [PDF, p. 9](https://arxiv.org/pdf/2303.11366v4#page=9)
- Appendices A–D. In Table 4, StarChat scores 0.26 in both HumanEval conditions. Table 5 shows that the effect on HotpotQA varies by model and solution method. Appendix B traces an ALFWorld run and reports no clear advantage on 100 WebShop tasks. Appendix C gives programming examples and prompts for the ablations. Appendix D illustrates retries with reflection, with reference context and with trajectory memory alone.
