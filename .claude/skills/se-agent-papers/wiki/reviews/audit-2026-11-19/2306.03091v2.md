# RepoBench: Benchmarking Repository-Level Code Auto-Completion Systems

## Sections and Appendices

- Sections 1–3, Figure 1 and Table 1. RepoBench evaluates cross-file definition retrieval, next-line prediction and the two stages together. Tree-sitter extracts imports and use sites. Older repositories can be used for training. The test set comprises 1,075 new Python repositories and 594 new Java repositories. It distinguishes the first use of a cross-file symbol, subsequent uses and in-file prediction. ## Independent check

For difficult first uses in Python, Table 2 reports acc@1 of 10.01% for Jaccard and 7.68% for Edit, a difference of 2.33 percentage points. UniXcoder achieved 17.70%. In Table 4, overall Python EM with Codex rises from 33.15% to 37.11%, a 3.96-point gain. Tables 2 and 6 give different results for the stated three input lines. In the corresponding acc@1 column, the appendix gives 11.24% for Jaccard. Appendix B explicitly identifies training subsets (8,000 XF-F and 4,000 XF-R), whereas Table 2 uses test data. The values apply to separate samples.
