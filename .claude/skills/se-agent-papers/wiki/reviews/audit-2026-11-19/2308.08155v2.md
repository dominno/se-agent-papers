## Main text. Programming through conversation

The agent interface separates sending, receiving and generating replies. A model, a function or a person can supply a reply. Termination and handoff rules help define the program. The authors discuss the risk of conversations entering loops and the need for oversight when executing code. Appendix A, Table 1 compares the capabilities of related frameworks at the time of publication. ## Applications and comparison table

Figures 3–4 cover mathematics, interactive retrieval, ALFWorld, OptiGuide, group chat and chess. The 69.48% score is for the full MATH test. Across 5,000 problems this is 3,474 correct solutions versus 2,759 for GPT-4 (55.18%), a gain of 715 solutions or 14.30 percentage points. A separate subset comprised 120 difficult questions from six categories excluding geometry. The two evaluations did not include all the same systems. The response mechanism supports model output, code execution and human input and stops the conversation when its termination condition holds. Figure 4a gives 69.48% and 55.18% on the full set of 5,000 problems specified in D.1, a difference of 715 correct solutions. A separate set of 120 tasks contains 20 from each of six level-5 categories. D.1 distinguishes autonomous and human-assisted modes and documents differences in tool capabilities.
