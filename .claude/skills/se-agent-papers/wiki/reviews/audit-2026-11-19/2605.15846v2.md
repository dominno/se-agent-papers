# RoadmapBench: Evaluating Long-Horizon Agentic Software Development Across Version Upgrades

Audit opened on 19 November 2026 · version `2605.15846v2`. [Paper record](../../sources/arxiv-2605.15846.md) · [arXiv record](https://arxiv.org/abs/2605.15846v2) · [Retrieval metadata](../../raw/metadata/2605.15846.metadata.json)

## Review of sections and appendices

- §§1–3, Table 1 and Figures 1–3. Each task reconstructs a multistage development plan between actual releases. A specification and behavioral tests define the goal relative to an earlier repository version. The 115 tasks come from 17 repositories in five languages. The median reference diff changes 3,714 lines. - Section 4, Figure 4 and Table 2. Each configuration was run once. In OpenHands, Opus 4.7 solved 45/115 tasks (39.1%) and Seed-2.0-Pro solved 6/115 (5.2%). In Terminus 2 the corresponding counts were 44/115 (38.3%) and 3/115 (2.6%). The authors report full solutions separately from the mean score with partial credit. [PDF, p. 6](https://arxiv.org/pdf/2605.15846v2#page=6) [PDF, p. 7](https://arxiv.org/pdf/2605.15846v2#page=7)
- §§5–6 and Figures 5–9. The authors examine difficulty and subtasks, environment differences, interaction costs and failure types. Implementation errors predominate more often for the strongest models, while compilation errors are more prominent for some weaker models. Error composition is reported at subtask level. - Appendices A–E, Table 3 and Figures 10–12. The authors note the absence of a maintainability assessment, discuss the use of open repositories and consider societal impact and human oversight. Project size and language representation are uneven. For example, the median number of files changed was 876 for Fyne and 2 for thread-pool. - Appendices F–H, Tables 4–6 and Figures 13–15. A sample specification, repository selection criteria, checks of test correctness and completeness, and reruns of the reference patch document how tasks were constructed. The authors explain how they classified failures, with breakdowns by model and case studies of integration errors. Table 6 classifies 3,603 items across a benchmark of 115 tasks.
