# TextGrad: Automatic "Differentiation" via Text

Review of version `2406.07496v1` • 19 November 2026 • 41 pages. [arXiv record](https://arxiv.org/abs/2406.07496v1) · [Metadata and license](../../raw/metadata/2406.07496.metadata.json) · [Paper record](../../sources/arxiv-2406.07496.md)

## Sections and appendices

- Sections 1–2. TextGrad represents operations and variables to optimize as a graph. Feedback from an LLM about later operations propagates to earlier variables. A separate update step proposes new text. The analogy to a gradient concerns the role feedback plays in the update. - Section 3, Tables 1–3. A code solution had to pass all hidden LeetCode tests. For QA, answers were optimized at test time. During prompt optimization, feedback from a stronger model guided edits to instructions for a cheaper model. TextGrad beat the reported DSPy configuration on Object Counting (91.9 vs. 84.9) and tied it on Word Sorting and GSM8K. ## Independent verification

In Table 2, GPT-4o improves from 51.0% to 55.0% on GPQA Diamond, a gain of 4.0 percentage points. Appendix D gives 198 questions. A separate Table 1 comparison on 39 LeetCode Hard tasks, with up to five iterations, yields 36% against 31% for rerun Reflexion and 26% for zero-shot prompting. These are gains of 5 and 10 percentage points, respectively. In Table 3 the method outperforms DSPy on one of three datasets.
