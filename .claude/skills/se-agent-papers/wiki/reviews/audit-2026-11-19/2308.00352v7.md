## Sections and evidence

- §§1–3 and Figures 1–3. Standard operating procedures divide the work among roles such as product manager, architect, project manager and engineer. Standardized documents and a shared message pool let each role subscribe to relevant information. The feedback-enabled variant executes the generated code and allows it to be revised. ## Independent verification

Figure 4 gives gains from enabling code execution of 85.9 − 81.7 = 4.2 points on HumanEval and 87.7 − 82.3 = 5.4 on MBPP. The SoftwareDev discussion places a score of 3.75 alongside 503 seconds. Table 1 assigns 503 seconds to the variant without execution and 541 seconds to the variant that scored 3.75. Table 4 provides a separate comparison over seven tasks, with averages of 27/7 ≈ 3.9 for MetaGPT and 15/7 ≈ 2.1 for ChatDev.
