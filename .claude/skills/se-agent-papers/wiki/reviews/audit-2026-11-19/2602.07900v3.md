# Rethinking the Value of Agent-Generated Tests for LLM-Based Software Engineering Agents

Independent audit on 19 November 2026 • 2602.07900v3 · [Paper record](../../sources/arxiv-2602.07900.md)

## Section-by-section review

- **I–II, Figure 1.** Resolution is determined by the official SWE-bench Verified tests on the patch. The agent acts through a shell in mini-SWE-agent. The authors collected public runs from six models on 500 tasks and generated another 500 runs for each of four models. They estimate the additional calls cost about $1,600. Deterministic extraction recognizes complete writes to specific Python filenames. The exit code applies to the entire shell action. [PDF, p. 1](https://arxiv.org/pdf/2602.07900v3#page=1) [PDF, p. 2](https://arxiv.org/pdf/2602.07900v3#page=2) [PDF, p. 3](https://arxiv.org/pdf/2602.07900v3#page=3)
- **III, Tables I–III.** Runs with a detected new test file ranged from 12/500 for GPT-5.2 to 493/500 for MiniMax M2. Among runs with a test, the mean interval from first to last write, measured as a fraction of the step count, was 0.38 for solved tasks and 0.43 for unsolved tasks. Mean numbers of file-execution actions were 4.82 and 6.45, respectively. The difference in executions per file loses significance after Holm correction. [PDF, p. 4](https://arxiv.org/pdf/2602.07900v3#page=4) [PDF, p. 5](https://arxiv.org/pdf/2602.07900v3#page=5)
- **IV, Tables IV–VI.** GPT-5.2 was excluded from the content analysis because it rarely wrote tests. Of 8,041 files, 8,028 could be parsed. In all ten combinations of five models and two task outcomes, statements that display values outnumber assertions on average. Exact comparisons predominate among assertions under all three alternative schemes for categorizing compound expressions. Across models, 70.12–77.94% of output statements print a specific value or specific content, the largest category in each model. [PDF, p. 5](https://arxiv.org/pdf/2602.07900v3#page=5) [PDF, p. 6](https://arxiv.org/pdf/2602.07900v3#page=6) [PDF, p. 7](https://arxiv.org/pdf/2602.07900v3#page=7) [PDF, p. 8](https://arxiv.org/pdf/2602.07900v3#page=8)
- **V, Figure 2 and Table VII.** The prompts were changed to encourage test writing for GPT-5.2 and Gemini or discourage it for Kimi and DeepSeek. Of 1,363 pairs with the expected behavioral change, 1,147 retained the same outcome. Exact paired McNemar tests with Holm correction give p > 0.05 for all four models. For Kimi, the 95% bootstrap interval for the difference in solve rate ranges from −6.4 to +1.2 percentage points. [PDF, p. 7](https://arxiv.org/pdf/2602.07900v3#page=7) [PDF, p. 8](https://arxiv.org/pdf/2602.07900v3#page=8) [PDF, p. 9](https://arxiv.org/pdf/2602.07900v3#page=9)
- **V, Table VIII.** For Kimi, input tokens per task fell from 668,449 to 340,689 (−49.0%), with 317 and 304 tasks solved, respectively. GPT-5.2 used 9.0% more input tokens and solved the same number of tasks. The analysis used paired comparisons of token counts with correction for multiple testing. [PDF, p. 8](https://arxiv.org/pdf/2602.07900v3#page=8) [PDF, p. 10](https://arxiv.org/pdf/2602.07900v3#page=10)
- **VI–IX. Discussion, limitations, related work, conclusions, and data.** One run per condition, differences in environment versions, and API access make it difficult to isolate the effect of the instruction. AST classification examines the syntax written to the file. How that code is used during subsequent diagnosis remains open. Related work covers persistent test generation and repair traces. The authors link to an external package containing data and scripts. The PDF ends with references.
