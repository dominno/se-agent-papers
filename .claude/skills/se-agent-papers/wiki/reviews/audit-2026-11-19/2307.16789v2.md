# ToolLLM: Facilitating Large Language Models to Master 16000+ Real-world APIs

Independent audit on 19 November 2026 • 2307.16789v2 · [Paper record](../../sources/arxiv-2307.16789.md)

## Sections and recalculation of metrics

Section 1, Figures 1–2 and Table 1 distinguish tools from API endpoints. The 3,451 tools expose 16,464 interfaces in 49 categories. The authors compare their 126,486 examples and 469,585 actual calls with earlier collections. In Section 2, Figures 3–4, ChatGPT generates instructions from combinations of related tools, searches the DFSDT tree and evaluates trajectories. The examples are used to fine-tune LLaMA-2 7B with an extended context window. Section 3 and Tables 2–4. The retriever averages 84.9 NDCG@5 versus 45.4 for Ada. With annotation generation budgets matched, ChatGPT scores 63.8% with DFSDT versus 44.5% with repeated ReAct. This is separate from the final test. On six subsets, ToolLLaMA with DFSDT and the specified APIs averages (57 + 61 + 62 + 77 + 77 + 66)/6 = 66.67% passes, versus 64.8% for ChatGPT with DFSDT. Pairwise scores against the common ChatGPT-ReAct baseline are 60.0 and 64.3, respectively. Table 5 tests transfer to APIBench. On the Hugging Face subset, API-call abstract syntax tree accuracy is 16.77% with the system’s own retriever and 88.80% when the correct API is supplied. Sections 4–5 relate these results to tool learning and instruction tuning. The findings depend on service availability and how API documentation is supplied. ## Appendix A

Sections A.1–A.4 document filtering of unstable or unavailable APIs, response truncation, training and search parameters. A.5 distinguishes instruction feasibility from answer quality. ToolEval’s agreement with humans was 87.1% on passes and 80.3% on comparisons. A.6 and Table 6 report wins and ties separately. For ToolLLaMA-DFSDT, mean wins of 55.2% plus 0.5 × 9.8% ties give about 60.1%, consistent with the main result after rounding. A.7–A.8 provide instruction-generation and path-search prompts and an extended documentation example.
