# SWE-PolyBench: A multi-language benchmark for repository level evaluation of coding agents

Audit opened on 19 November 2026 for version `2504.08703v3`, 20 pages. [Paper record](../../sources/arxiv-2504.08703.md) · [arXiv record](https://arxiv.org/abs/2504.08703v3) · [Authors, license and checksum](../../raw/metadata/2504.08703.metadata.json)

## Sections and Tables

- Sections 1–3. The authors selected public tasks linked to accepted patches and a reproducible test that passed after the change. They built execution environments and excluded repositories already in SWE-Bench. The focus on testable fixes limits how well the benchmark represents project work as a whole. [PDF, p. 2](https://arxiv.org/pdf/2504.08703v3#page=2) [PDF, p. 3](https://arxiv.org/pdf/2504.08703v3#page=3) [PDF, p. 4](https://arxiv.org/pdf/2504.08703v3#page=4)
- Section 4, Tables 1–2, and Figure 3. The authors counted modified files and classified the types of syntax-tree nodes involved. A language model classified tasks and the informativeness of issues with access to the reference patch. The 500-task subset balances the languages, while JavaScript and TypeScript dominate the full dataset. [PDF, p. 5](https://arxiv.org/pdf/2504.08703v3#page=5) [PDF, p. 6](https://arxiv.org/pdf/2504.08703v3#page=6) [PDF, p. 7](https://arxiv.org/pdf/2504.08703v3#page=7)
- Section 5, Tables 3–6. The authors adapted three agents to four programming languages. Patch correctness depends on regression tests and new tests. Localization agreement compares the files and nodes changed by the agent with those changed by a human. Aider-PB with Sonnet 3.5 scores 14.1% ± 0.77 percentage points (bootstrap standard error), compared with 10.2% and 7.8% for the other two configurations using the same base model. - Sections 6–7. Passing tests and agreement with human fault localization do not establish overall solution quality. Limits include the absence of full manual validation that the tasks were solvable and the possibility that the models had encountered the public repositories. ## Independent check

In the file released by the authors, **test.csv** the reviewer counted 2,110 records from 21 repositories: 1,017 JavaScript, 729 TypeScript, 199 Python, and 165 Java. The abstract matches the released data, while Table 9 overstates the JavaScript task count by 61. Separately, the rounded means in Table 1 imply (2.6 − 1.6)/1.6 = 62.5% more files modified than in the full SWE-Bench dataset.
