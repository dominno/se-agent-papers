# Mem0: Building Production-Ready AI Agents with Scalable Long-Term Memory

Review of version `2504.19413v1` • 19 November 2026 • 23 pages. [arXiv record](https://arxiv.org/abs/2504.19413v1) · [Metadata and license](../../raw/metadata/2504.19413.metadata.json) · [Paper record](../../sources/arxiv-2504.19413.md)

## Sections, Tables and Appendices

- Sections 1–2. Mem0 extracts facts using the summary and recent messages as context, retrieves similar memories and updates their content. Figures 1–3 illustrate context loss, the basic memory system and a graph variant linking entities through relations with metadata. - Section 3. The LoCoMo evaluation uses 10 long conversations and four question categories. Questions without a reference answer were excluded. The authors report F1, BLEU-1 and a model-judge score (J), giving the mean and standard deviation of ten judgments for J. Baselines include RAG with different chunk sizes, full-context prompting and ChatGPT memory accessed through the product interface. - Section 4. In Table 1, the graph variant has a higher judge score (J) than the base variant on temporal questions (58.13 vs. 55.51) and a lower score on multi-hop questions (47.19 vs. 51.15). Zep has the highest J for open-ended questions. Table 2 and Figure 4 distinguish retrieval time from end-to-end response time. The system stores about 7,000 tokens per conversation and sends an average of 1,764 tokens to the model. These figures measure different operations. ## Independent verification

In Table 2, total p95 latency falls by 1 − 1.440/17.117 = 91.59%, and the context token count falls by 1 − 1,764/26,031 = 93.22%. J declines by 6.02 percentage points (72.90% to 66.88%). Compared with ChatGPT memory, the increase from 52.90% to 66.88% is 13.98 points, or 26.43% relative. These comparisons use different denominators.
