# SWE-Doctor: Guiding Software Engineering Agents with Runtime Diagnosis from Multi-Faceted Bug Reproduction Tests

Review of version `2607.00990v1` • 19 November 2026 • 12 pages. [arXiv record](https://arxiv.org/abs/2607.00990v1) · [Metadata and license](../../raw/metadata/2607.00990.metadata.json) · [Paper record](../../sources/arxiv-2607.00990.md)

## Section review

- **I–II, Figure 1 and Table I.** In a preliminary sample of 100 randomly selected SWE-bench Verified issues, three test generators paired with mini-SWE-agent solved 71, 71 and 73 issues, compared with 74 for the baseline. A test that passes after the reference patch may cover only some requirements. The Django example distinguishes an editable field from a read-only one. [PDF, p. 1](https://arxiv.org/pdf/2607.00990v1#page=1) [PDF, p. 2](https://arxiv.org/pdf/2607.00990v1#page=2) [PDF, p. 3](https://arxiv.org/pdf/2607.00990v1#page=3) [PDF, p. 4](https://arxiv.org/pdf/2607.00990v1#page=4)
- **III, Figure 2.** For each requirement in the issue, the agent prepares a test and identifies the relevant code. It discards environment failures that occur before that code runs and accepts a diagnosis only after observing the running program. Mini-SWE-agent receives the location, requirement and diagnosis. If no diagnosis is available, it uses its baseline procedure. [PDF, p. 4](https://arxiv.org/pdf/2607.00990v1#page=4) [PDF, p. 5](https://arxiv.org/pdf/2607.00990v1#page=5) [PDF, p. 6](https://arxiv.org/pdf/2607.00990v1#page=6)
- **IV–V, RQ1 and RQ2.** The main evaluation includes 436 Verified issues and 107 Pro issues from Python repositories, five models and two baselines. Table II reports mean resolution rates of 75.7% and 59.4%. Figure 3 aggregates issues solved uniquely by an agent across model–dataset configurations, so the same issue can count more than once. Table III separates tests that pass after the reference patch from those that still fail. In the latter group SWE-Doctor outperforms mini-SWE-agent in eight of ten configurations. Mean cost per issue is $0.43 on Verified and $0.64 on Pro, higher than both baselines. [PDF, p. 6](https://arxiv.org/pdf/2607.00990v1#page=6) [PDF, p. 7](https://arxiv.org/pdf/2607.00990v1#page=7) [PDF, p. 8](https://arxiv.org/pdf/2607.00990v1#page=8)
- **V, RQ3–RQ5.** In an ablation on 50 Pro issues with GPT-5.4-mini, the full system achieved 56% versus 48% without diagnosis (Table IV). On tests that still failed after the reference patch, the rates were 53.1% and 40.6% (Table V). Across five runs on a 50-task sample, Pass@5 was 70%, All@5 was 40% and the mean was 54% (Table VI). On a separate set of 50 Go issues with Delve and DeepSeek-V4-Pro, SWE-Doctor, mini and live achieved 36%, 32% and 30%, respectively (Table VII). [PDF, p. 8](https://arxiv.org/pdf/2607.00990v1#page=8) [PDF, p. 9](https://arxiv.org/pdf/2607.00990v1#page=9) [PDF, p. 10](https://arxiv.org/pdf/2607.00990v1#page=10)
- **VI–IX, Bibliography.** Limitations include the scope of the two benchmarks, the choice of baselines and models, and variation across runs. The review distinguishes generating a test, validating an existing patch and using observations before generating a patch. The authors identify a public repository with the implementation and data. The PDF ends with the references and has no separate appendix.
