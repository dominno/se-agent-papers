# Ragas: Automated Evaluation of Retrieval Augmented Generation

Audit opened on 19 November 2026 for version `2309.15217v2`, 8 pages. [Paper record](../../sources/arxiv-2309.15217.md) · [arXiv record](https://arxiv.org/abs/2309.15217v2) · [Authors, license and checksum](../../raw/metadata/2309.15217.metadata.json)

## Reading notes

| Section | Finding and supporting evidence |
|---|---|
| 1. Introduction | Perplexity requires access to token probabilities and can be a poor predictor of downstream usefulness. The authors evaluate retrieval separately from how well the answer uses the retrieved context. [PDF, p. 1](https://arxiv.org/pdf/2309.15217v2#page=1) [PDF, p. 2](https://arxiv.org/pdf/2309.15217v2#page=2) |
| 2. Related work | The authors compare approaches using probabilities or hidden states, repeated sampling, scoring against a reference answer and LLM-based ranking. Candidate order can influence the judge’s choice. [PDF, p. 2](https://arxiv.org/pdf/2309.15217v2#page=2) |
| 3. Assessment strategies | Faithfulness is the fraction of answer statements the judge finds entailed by the context. Answer relevance is the mean cosine similarity between the original question embedding and embeddings of questions generated from the answer. Context relevance is the fraction of context sentences selected as necessary. The authors used gpt-3.5-turbo-16k and text-embedding-ada-002. [PDF, p. 3](https://arxiv.org/pdf/2309.15217v2#page=3) [PDF, p. 4](https://arxiv.org/pdf/2309.15217v2#page=4) |
| 4. WikiEval | The authors selected 50 Wikipedia pages about events from 2022 onward and constructed contrasting answers and contexts. Two English-speaking annotators resolved disagreements by discussion. Initial agreement was approximately 95% for faithfulness and context relevance and 90% for answer relevance. [PDF, p. 4](https://arxiv.org/pdf/2309.15217v2#page=4) [PDF, p. 5](https://arxiv.org/pdf/2309.15217v2#page=5) |
| 5. Experiments, Table 1 | For choosing the preferred item in a pair, accuracy was 0.95/0.78/0.70 for Ragas, 0.72/0.52/0.63 for GPT Score, and 0.54/0.40/0.52 for GPT Ranking. The columns represent faithfulness, answer relevance, and context relevance. GPT Score ties were broken at random. The table reports point estimates. [PDF, p. 5](https://arxiv.org/pdf/2309.15217v2#page=5) |
| 6. Conclusions | Selecting relevant information from the context was hardest, particularly with long contexts. The constructed pairs test how often the metrics agree with human preferences. The validation does not establish performance for arbitrary production RAG systems. [PDF, p. 4](https://arxiv.org/pdf/2309.15217v2#page=4) [PDF, p. 5](https://arxiv.org/pdf/2309.15217v2#page=5) |
| References and Appendix A | The references cover alternative factuality metrics and candidate-order effects. Table 2 alters facts about a film. Table 3 compares a complete answer about a mission launch with one that omits the time and place. Table 4 contrasts a concise context with a longer description of the same tower. Each example illustrates a different evaluation dimension. [PDF, p. 6](https://arxiv.org/pdf/2309.15217v2#page=6) [PDF, p. 7](https://arxiv.org/pdf/2309.15217v2#page=7) [PDF, p. 8](https://arxiv.org/pdf/2309.15217v2#page=8) |

## Independent check of the paper card’s findings

All six values on the card match the columns in the image of Table 1. The respective differences from GPT Score are 23, 26 and 7 percentage points. The paper provides no confidence intervals for those differences. [PDF, p. 5](https://arxiv.org/pdf/2309.15217v2#page=5)

The authors’ public dataset contains 50 rows. Both answers to the PSLV-C56 mission question match Table 3, confirming the dataset size and the construction of that example. The accuracy figures come from Table 1. [PDF, p. 4](https://arxiv.org/pdf/2309.15217v2#page=4) [PDF, p. 5](https://arxiv.org/pdf/2309.15217v2#page=5) [PDF, p. 8](https://arxiv.org/pdf/2309.15217v2#page=8) [WikiEval data](https://huggingface.co/datasets/vibrantlabsai/WikiEval)

A second reviewer read all nine cells for Ragas, GPT Score and GPT Ranking from the image of Table 1 and verified which evaluation dimension each column represents. [PDF, p. 5](https://arxiv.org/pdf/2309.15217v2#page=5)
