# MemGPT: Towards LLMs as Operating Systems

Review of version `2310.08560v2` • 19 November 2026 • 13 pages. [arXiv record](https://arxiv.org/abs/2310.08560v2) · [Metadata and license](../../raw/metadata/2310.08560.metadata.json) · [Paper record](../../sources/arxiv-2310.08560.md)

## Section review

- **1–2. Memory and control.** The main context contains instructions, editable working memory and a FIFO queue. Message history and archival memory reside outside the context window. The queue manager records message history and handles overflow. The function executor brings selected result pages into the window. Multiple reads can occur in one cycle before the agent replies. Figures 1–4 illustrate storage, retrieval, data flow and updates. Table 1 compares model context windows as of January 2024. - **3.1. Conversations, Tables 2–3.** A synthetic question about an earlier fact was added to five Multi-Session Chat sessions. The baseline received a recursive summary and MemGPT could page through the full history. With GPT-4, DMR accuracy rose from 32.1% to 92.5% and ROUGE-L recall from 0.296 to 0.814. On conversation openers, SIM-1 and SIM-3 measure similarity to persona data. MemGPT with GPT-4 scored 0.868 and 0.843, versus 0.800 on both for the human utterance. This is an indirect measure of engagement. - **3.2. Documents, Figures 5–8.** All systems used the same vector search for 50 NaturalQuestions-Open questions. The agent could revise a query repeatedly and page through the results. The baseline received retrieved documents once, truncated to fit its context window when necessary. The multi-step lookup task used 140 identifier pairs and 30 orderings. At depth 3, Figure 7 shows 1.0 for MemGPT with GPT-4, about 0.6 with GPT-4 Turbo and zero for the baselines. GPT-3.5 with memory also dropped to zero. - **4–5, bibliography and 6.1.** Related work covers longer context windows, retrieval and active tool use. The appendix provides abbreviated DMR prompts, rules for lenient grading against a reference answer, question generation from the log, the document task’s source-citation requirement and instructions for key–value lookup. The prompts and access to source material vary as part of the system under evaluation.
