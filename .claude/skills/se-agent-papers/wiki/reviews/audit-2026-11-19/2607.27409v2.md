# SWE-NFI: Studying and Benchmarking Coding Agents for Non-Functional Improvements

Independent audit on 19 November 2026 • 2607.27409v2 · [Paper record](../../sources/arxiv-2607.27409.md)

## Section-by-section review

- **1–2. Motivation and earlier Benchmarks.** The study measures how the quality of existing code changes while the behavior checked by the tests is preserved. The authors compare this objective with measuring task resolution, performance, security and instruction following. [PDF, p. 1](https://arxiv.org/pdf/2607.27409v2#page=1) [PDF, p. 2](https://arxiv.org/pdf/2607.27409v2#page=2) [PDF, p. 3](https://arxiv.org/pdf/2607.27409v2#page=3)
- **3, Figure 1 and Tables 1–2.** From the literature, issue reports and Python guidance, the authors derived 92 checkable rules covering documentation, errors, libraries, style and logic. Table 1 lists 17 requirements, 54 prohibitions and 21 threshold rules. Table 2 gives examples, including thresholds selected by the authors. The score is the percentage-point change in the share of satisfied rules within a category. [PDF, p. 3](https://arxiv.org/pdf/2607.27409v2#page=3) [PDF, p. 4](https://arxiv.org/pdf/2607.27409v2#page=4) [PDF, p. 5](https://arxiv.org/pdf/2607.27409v2#page=5)
- **3.3–4. Selection and protocol.** The study started with 226,955 pull-request–file pairs. Only tasks with a positive change under the human revision were eligible. Review and selection yielded 188 tasks from 48 repositories, including 145 single-file and 43 multi-file tasks. Eight configurations each had five attempts per task. Stage one required nonempty, syntactically valid code. Stage two required passing the task’s functional checks. [PDF, p. 5](https://arxiv.org/pdf/2607.27409v2#page=5) [PDF, p. 6](https://arxiv.org/pdf/2607.27409v2#page=6)
- **5, RQ1–2 and Tables 3–4.** Claude Code Agent had the highest mean second-stage pass rate (70.0% of valid outputs). Mean improvement in Logic Patterns ranged from 0.0 to 1.3 percentage points, compared with 1.5 for the human reference. On the multi-file set, two mini-SWE configurations produced no eligible output. Table 4 distinguishes missing data for these configurations from a measured zero. [PDF, p. 7](https://arxiv.org/pdf/2607.27409v2#page=7) [PDF, p. 8](https://arxiv.org/pdf/2607.27409v2#page=8)
- **5, RQ3–4, Table 5 and Figure 2.** A stable score can be consistently low. Mini-SWE with GPT-4.1 achieved aggregate NFI of zero in all five repetitions. Cost per success divides the cost of all attempts by the number of outputs preserving function and improving the target aspect. In this study the means were 424,970 tokens and 120.02 seconds for Claude Code Agent and 4,339 tokens and 21.08 seconds for Codex. [PDF, p. 9](https://arxiv.org/pdf/2607.27409v2#page=9) [PDF, p. 10](https://arxiv.org/pdf/2607.27409v2#page=10)
- **6, Figure 3.** Two changes to the same file pass the checks but expand its documentation to different extents. The authors report improvements of 21.05 and 10.53 percentage points. They recommend interpreting the score in the context of the project and the rules under consideration. [PDF, p. 10](https://arxiv.org/pdf/2607.27409v2#page=10) [PDF, p. 11](https://arxiv.org/pdf/2607.27409v2#page=11)
- **7–8, bibliography.** Thresholding can miss a real improvement when both versions fall on the same side of the cutoff. All rules within an aspect are weighted equally. The sample is uneven, with 90 documentation tasks and a single multifile Logic Patterns task. References follow the conclusions. The text provides no direct link to the data package. [PDF, p. 11](https://arxiv.org/pdf/2607.27409v2#page=11) [PDF, p. 12](https://arxiv.org/pdf/2607.27409v2#page=12) [PDF, p. 13](https://arxiv.org/pdf/2607.27409v2#page=13)

## Independent verification

The eligibility counts sum to 6,775 + 211,914 + 7,566 + 700 = 226,955 pull-request–file pairs. The five rounded Claude Code Agent rates in Table 5 average (67.1 + 71.0 + 69.8 + 70.1 + 71.9)/5 = 69.98%, matching 70.0% in Table 3. This is the highest configuration mean. The highest single repetition scored 71.9%. With 19 documentation rules as the denominator, the two cases in Figure 3 gained four and two rules net, respectively.
