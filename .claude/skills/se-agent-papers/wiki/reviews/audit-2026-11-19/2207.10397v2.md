# CodeT: Code Generation with Generated Tests

Review of version `2207.10397v2` • 19 November 2026 • 19 pages. [arXiv record](https://arxiv.org/abs/2207.10397v2) · [Metadata and license](../../raw/metadata/2207.10397.metadata.json) · [Paper record](../../sources/arxiv-2207.10397.md)

## Section review

- **1–3, Figures 1–3 and Table 1.** CodeT samples multiple programs and assertions with the same model. Two solutions belong to the same group if they pass the same set of generated tests. Ranking depends on the number of solutions and tests in an agreement group. Final evaluation uses separate reference tests. Four benchmarks were studied, including 164 HumanEval tasks and 427 MBPP tasks. - **4, Tables 2–5, and Figures 4–5.** On modified HumanEval, code-davinci-002 achieves 65.8% pass@1 versus 47.0% in the baseline condition. On zero-shot CodeContests, the scores are 2.1% and 0.7%. The authors examine candidate counts, test correctness, harm from incorrect tests, and examples of reliable and misleading groups. - **5–6 and bibliography.** The paper compares approaches to code generation, behavioral selection of code and test generation. The highest-consensus group may contain solutions that share the same misinterpretation of the task. [PDF, p. 8](https://arxiv.org/pdf/2207.10397v2#page=8) [PDF, p. 9](https://arxiv.org/pdf/2207.10397v2#page=9) [PDF, p. 10](https://arxiv.org/pdf/2207.10397v2#page=10) [PDF, p. 11](https://arxiv.org/pdf/2207.10397v2#page=11)
- **A–E, Tables 6–7 and Figures 6–9.** The implemented ranking reduces the influence of program count by taking its square root. The main setting removes example inputs and outputs from task descriptions. Restoring them raises CodeT with code-davinci-002 from 65.8% to 74.8%. Analyses cover group count, duplicates and temperature. Deduplication helps on some tasks and hurts on others. [PDF, p. 12](https://arxiv.org/pdf/2207.10397v2#page=12) [PDF, p. 13](https://arxiv.org/pdf/2207.10397v2#page=13) [PDF, p. 14](https://arxiv.org/pdf/2207.10397v2#page=14)
- **F–J, Tables 8–13 and Figures 10–11.** Removing trivial outputs had little effect. One-shot results for APPS and CodeContests are reported separately. The authors also report the count of extracted assertions, statement and branch coverage, the testing budget, and rankings based solely on code or on tests. On HumanEval, code-davinci-002 scored 55.9% and 58.4% in those two ablations, versus 65.8% with the full ranking. The closing examples illustrate missed edge cases and misread specifications. ## Independent verification

Values from Tables 2 and 6 in **PDF** confirms that 65.8 − 47.0 = **18.8 percentage points** for descriptions without examples. On the original HumanEval benchmark, the difference is 74.8 − 47.6 = **27.2 percentage points** Baseline pass@1 uses greedy decoding at temperature 0, while CodeT selects among 100 samples generated at temperature 0.8. The comparison covers complete procedures with different budgets. Table numbers follow the PDF because the HTML renderer classifies the statistics table differently.
