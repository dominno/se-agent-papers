# A-MEM: Agentic Memory for LLM Agents

Independent audit on 19 November 2026 • 2502.12110v11 · [Paper record](../../sources/arxiv-2502.12110.md)

Sections 1–3. A-MEM stores content, a vector representation, keywords, tags and a context description. It retrieves neighboring entries, after which the model can create links and revise descriptions of earlier notes. At query time, it retrieves the nearest entries. Section 4 and Tables 1–4. On temporal LoCoMo questions with GPT-4o-mini, F1 rises from 25.52 for MemGPT to 45.85 for A-MEM (+20.33 points). On multi-hop questions it rises from 26.65 to 27.02 (+0.37 points). On adversarial questions, full-history LoCoMo scores 69.23 versus 50.03 for A-MEM. On DialSim, Table 2 gives 3.45 versus 2.55 for LoCoMo and 1.18 for MemGPT. Table 3 separately examines removal of memory updating and removal of both modules. At one million entries, Table 4 reports 3.70 μs retrieval latency and 1,464.84 MB memory use for the retrieval component. Sections 4.5–6 and Appendix A. The authors select k by category and model. For GPT-4o-mini, Table 1 reports 2,520 tokens versus 16,977 for MemGPT (−85.16%). The general description says about 1,200 and the GPT-4o value is 1,216. Tables 5–7 add ROUGE, METEOR and semantic similarity. Table 8 gives values of k. The t-SNE plots illustrate selected conversations and do not quantify answer quality.
