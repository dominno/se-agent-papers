## Sections and sources of results

- Sections 1–2. In step H, the current model proposes changes to the control code and retains the highest-scoring variant. In step P, it learns from verified task outcomes. Unsolved tasks supply the next H round. Algorithm 1 and Figures 1–2 distinguish the two optimization targets. - Section 3. Training used 2,484 tasks, two rounds, six H candidates and 50 RL updates per round. Table 1 gives three-run means for Verified (500 tasks), Multilingual (300) and public SWE-Bench Pro V2 (642). Table 2 compares training and task selection. Table 3 crosses three policies with three harness variants. Figures 3–4 distinguish update history, pass@k and the proportion of groups with no success. Among tasks the base model always solved, pass@1 fell by 2.2 points.
