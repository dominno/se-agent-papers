# Large Language Models as Optimizers

Independent audit on 19 November 2026 • 2309.03409v3 · [Paper record](../../sources/arxiv-2309.03409.md)

Sections 1–2 and Table 1. The model proposes solutions using the task description and a history of solution–score pairs. An external function evaluates each proposal. Section 3 and Tables 2–3 examine simple linear regression and the traveling salesperson problem. For ten cities, each of three models found the optimum on 5/5 instances. For 50 cities, each succeeded on 0/5. The mean step counts in Table 3 include only instances where the optimum was found. Sections 4–5 and Tables 4–6. The optimizer edits instructions and a separate model answers the tasks. On GSM8K with PaLM 2-L as the answering model, the best instruction from PaLM 2-L-IT yields 80.2%, compared with 71.8% for the hand-written step-by-step reasoning prompt. The increase is 8.4 percentage points. Table 4 explicitly gives the best test accuracy for the model pair. Table 5 shows task-specific instructions, and Table 6 examines transfer to MultiArith and AQuA. Ablations vary initialization, ordering, the treatment of scores for earlier proposals, and temperature.
