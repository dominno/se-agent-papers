## Sections and quantitative results

Sections 1–3 and Figure 1 describe retrieving documentation for a user intent. BM25 or a contrastively trained encoder selects the top k. T5 encodes each passage with the intent separately, and its decoder combines the representations. Codex receives examples in context. ## Appendices and checks on the reported results

Appendices A–B, Table 6. The counts 6,414 + 1,845 + 928 total 9,187 tldr pairs. The command counts 1,315 + 376 + 188 total 1,879, consistent with Section 4. The same appendix gives 1,897 in one place. Unit tests cover 100 randomly sampled CoNaLa tasks out of 543, averaging 2.03 tests per task, with one annotator assigned to each task. Appendices C–E document training of both components and three example Codex inputs in Table 7.
