# NL2Repo-Bench: Towards Long-Horizon Repository Generation Evaluation of Coding Agents

## Sections, Tables and Appendices

- Sections 1–3. The authors compare generating a library with repairing an existing project. Figures 1–2 show the requirements and task construction process. Experts derived API descriptions from existing projects, analyzed syntax trees and checked that tests matched the specifications. Tables 1–2 describe 104 Python libraries in nine categories, with 26 easy, 46 medium and 32 hard tasks. ## Independent verification

The earlier card placed all configurations below 40%. Tables 3 and 8 give 40.2% for Sonnet-4.5 in Claude Code, while Table 3 gives 39.9% for the same model in OpenHands. The conclusion on page 18 mentions 39.6% without reconciling it with those rows. With tests visible to the agent in Table 8, the score rises by 19.2 percentage points and the number of fully solved projects rises from 3 to 18. This condition gives the agent access to additional evaluation information.
