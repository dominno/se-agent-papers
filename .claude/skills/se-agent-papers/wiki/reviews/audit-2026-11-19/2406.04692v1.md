## Review of sections, tables and appendices

- Sections 1–2. Several models answer the same question in the first layer. Each subsequent layer receives the preceding layer’s answers. Table 1 gives the synthesis prompt. The aggregator can combine ideas from several answers, while the comparison ranker selects one existing answer. The analogy with a mixture of experts concerns combining the specializations of whole models through a text interface. - Sections 3.1–3.2 and Table 2. The main configuration uses six proposers, three layers and Qwen1.5-110B as the final model. On 805 AlpacaEval instructions, each answer is compared with the same GPT-4 Preview reference answer. The length-controlled win rate for open MoA is 65.1 ± 0.6% (mean and SD of three runs), versus 57.5% for GPT-4o. On MT-Bench, open MoA scores 9.25 versus 9.31 for GPT-4 Turbo. Aggregation with GPT-4o scores highest at 9.40. Figure 3 breaks FLASK down into 12 skills. - §§3.3–3.4, Tables 3–4 and Figures 4–5. For n = 2, 3 and 6, using different proposer models outperforms repeated sampling from a single model. The best choice for the proposer and aggregator roles depends on the model. Costs use May 2024 prices. The latency estimate assumes parallel execution and an unconfirmed parameter count for GPT-4. The final layer must wait for earlier layers before generating the first token of its answer. ## Independent check

Relative to the shared baseline, 65.1 − 57.5 = **7.6 percentage points** This is the difference between the rates for two systems. The introduction also reports 65.8%, while Table 2 gives 65.7% for the GPT-4o configuration and 65.1% for the open configuration. Table 3 contradicts the claim that performance increases monotonically with the number of proposers. The score is 58.8% with two distinct models, 58.0% with three and 61.3% with six.
