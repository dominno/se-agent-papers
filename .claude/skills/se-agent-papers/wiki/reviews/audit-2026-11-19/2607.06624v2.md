## Sections and appendices

- §§1–3. Interviews about working in a development environment informed 16 scenarios, each with two simulated user profiles. Table 1 lists the verifiers. Passing a scenario requires passing every applicable check. Figure 1 shows a qualitative report. The QI index is the unweighted mean of the formal score and five model ratings. ## Independent verification

In Table 6, the identical formal score of 81.2 is the percentage of scenarios passing every check. Averaging percentages for individual tests would yield a different metric. For EAA the rounded components give (81.2 + 94 + 75 + 64 + 92 + 83)/6 = 81.53. For Claude Code the six components yield 76.20 under the same calculation. The Figure 2 distribution, 1 + 3 + 5 + 4 + 4 + 15 = 32, includes 16 cases that passed between one and four of five attempts.
