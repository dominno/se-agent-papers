# RepoZero: Can LLMs Generate a Code Repository from Scratch?

Review of version `2605.07122v3` • 19 November 2026 • 16 pages. [arXiv record](https://arxiv.org/abs/2605.07122v3) · [Metadata and license](../../raw/metadata/2605.07122.metadata.json) · [Paper record](../../sources/arxiv-2605.07122.md)

## Section review

- **1–3, Table 1 and Figures 1–2.** The paper compares existing benchmarks and constructs tasks that reproduce a library’s behavior in a second language. The unit of evaluation is a **test file that calls the API**. The authors obtained 400 Python→JavaScript and 200 C/C++→Rust samples of this type from the selected repositories. These are not 600 independent repositories. A model generates tests, and executing the original program supplies expected outputs. The authors filter unstable or unexecutable cases. Some examples are public and the rest remain hidden. - **4–5. ACE and metrics.** ACE generates additional tests, compares behavior with the original, and returns differences to the agent for correction. PR requires agreement across all required outputs in a sample. SR is the proportion of individual cases that pass. The study compares OpenHands-bash and Mini-SWE-Agent. [PDF, p. 5](https://arxiv.org/pdf/2605.07122v3#page=5) [PDF, p. 6](https://arxiv.org/pdf/2605.07122v3#page=6)
- **6, Tables 2–4 and Figures 3–4.** Claude-4.6-Sonnet in Mini-SWE-Agent achieved mean PR of 54.70% for Py2JS and 47.58% for C2Rust. With OpenHands-bash, the corresponding rates were 51.46% and 44.60%. For DeepSeek V3.1 on Py2JS, two ACE rounds raised PR from 26.08 to 42.88 in OpenHands-bash and from 43.76 to 52.06 in Mini-SWE-Agent. The analysis distinguishes programs that fail to run from those that run but produce different outputs. The cost plot covers OpenHands-bash. [PDF, p. 7](https://arxiv.org/pdf/2605.07122v3#page=7) [PDF, p. 8](https://arxiv.org/pdf/2605.07122v3#page=8) [PDF, p. 9](https://arxiv.org/pdf/2605.07122v3#page=9)
- **7–8 and limitations.** The authors compare cross-language transfer of entire repositories with editing and feature-addition benchmarks. Checking examples does not directly measure the architectural quality of the reconstruction. The source libraries and the two language directions limit generalization. [PDF, p. 3](https://arxiv.org/pdf/2605.07122v3#page=3) [PDF, p. 9](https://arxiv.org/pdf/2605.07122v3#page=9) [PDF, p. 10](https://arxiv.org/pdf/2605.07122v3#page=10)
- **References and Appendices A–C.** Table 5 groups Py2JS results into five domains. Table 6 reports success on individual cases. Table 7 shows a small change in SR from the first to the second round despite a larger change in PR. For Mini-SWE-Agent, SR rises from 72.32 to 72.93 and PR from 45.67 to 52.06. The appendix gives about 40 retained cases per file on average (minimum 20, maximum 60). The final pages provide templates for both migration directions and instructions for revising existing code. ## Independent verification

In Table 4, the OpenHands-bash gain is 42.88 − 26.08 = **16.80 percentage points**, and for Mini-SWE-Agent, 52.06 − 43.76 = **8.30 percentage points** Table 5 has an interpretation problem. All five values labeled category-level PR for DeepSeek V3.1/OpenHands-bash (35.08–63.88) exceed the overall PR of 26.08 in Table 2. Weighting those five values by category sizes cannot reproduce the reported overall PR. The publication card uses the main results tables.
