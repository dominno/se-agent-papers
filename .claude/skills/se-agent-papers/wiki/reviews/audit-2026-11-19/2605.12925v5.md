## Sections 1–4. Evaluating the execution trace

AgentLens normalizes tool events, labels each work stage using the preceding steps and merges successful runs of a task into a prefix tree (PTA). Its score combines structural alignment, consistency, timing and state coverage. The authors set the weights using 278 trajectories from 10 tasks. Each run was excluded from its own reference tree. ## Sections 5–7. Result and denominator check

Tables 1–3 respectively examine cases labeled Lucky, model configurations and diagnostic signals. Of 1,815 trajectories across 47 tasks, 1,136 passed the tests. Of the passing runs, 122/1136 (10.74%) were labeled Lucky. Removing 15 valid strategies that differed from the reference leaves 107/1136 (9.42%). The two largest categories account for (42 + 41)/122 = 68.03%. These labels follow the authors’ classification rules. Overall AUROC for predicting a pass was 0.766. Simple matching against individual reference patterns achieved 0.805. PTA can also identify where a solution diverges from known solutions. Label validation covered 192 of the 200 states that met the annotator-agreement threshold. ## Independent source check

The pilot used 278 runs on 10 tasks. In the main evaluation, 47 of 60 tasks met the inclusion criterion. Each reference tree excludes the run being evaluated. Both 122/1136 = 10.74% and (122 − 15)/1136 = 9.42% use successful trajectories as the denominator. The extremes of 0.5% and 23.2% refer to separate configurations. When predicting success, individual trajectory matching achieved AUROC 0.805 and the tree achieved 0.766.
