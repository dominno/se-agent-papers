# SWE-MeM: Learning Adaptive Memory Management for Long-Horizon Coding Agents

## Sections and Appendices

- Sections 1–2. The agent chooses when to compress, which steps to include and what the summary retains. Training involves synthesizing and filtering trajectories, successive stages of supervised learning and reward optimization with step masking. The objective is to preserve information useful for repairs within a limited context window. ## Independent check

For the 30B model, Table 1 shows an increase from the baseline of 51.6% to 60.2% (a gain of **8.6 percentage points**), but the gain from SFT to SFT+RL is only 60.2 − 58.8 = **1.4 percentage points** In Table 4, compressed length divided by original length is 1496.52/9657.93 = **15,5%**, giving a reduction of about 84.5% when calculated from these means.
