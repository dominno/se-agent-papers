## Sections and evidence

- §§1–3, Figures 1–2 and Table 1. Existing tests and code dependencies were used to identify callable functions in each repository. Checks verify that removing a function causes the expected failures while the remaining tests pass, and that restoring the reference change clears those failures. Levels L1 and L2 differ in how much existing code is available. ## Independent verification

The final dataset description gives a denominator of 200. Thus 12.5% is 25 tasks for Codex with GPT-5.1-Codex, 11.0% is 22 for Claude Code with Opus 4.5, and 10.5% is 21 for OpenHands with the same model. On Lite in Table 7, revealing the tests raises the Codex score from 20.0% to 63.3%, a gain of 43.3 percentage points. The standard Full evaluation uses different conditions. The naming-error analysis applies to the configuration in Figure 4.
