# Autonomous Deep Agent

**Paper:** [2502.07056](https://arxiv.org/abs/2502.07056) · [PDF](https://arxiv.org/pdf/2502.07056) · [HTML](https://arxiv.org/html/2502.07056)  
**Review status:** `fulltext_reviewed` · **Full text reviewed:** **yes**

## Research findings

**Method.** Deep Agent separates planning and execution. Plans can be recursively refined, and repeated interface interactions can be converted into reusable tools. [PDF, p. 1](https://arxiv.org/pdf/2502.07056v1#page=1)

**Key result.** In §2.4, the authors report a qualitative observation that several rounds of inference and reflection helped the agent choose when to ask questions and adapt its interface options. They give neither a scenario count nor an effect size. [PDF, p. 6](https://arxiv.org/pdf/2502.07056v1#page=6)

**Limitations and scope.** The figures illustrate execution flows. Reported approximate times cover prompt processing and one order. The paper does not compare costs on a common task set. ## Overview

The authors present a hierarchical task graph and an iterative cycle of planning, execution and local replanning. [PDF, p. 1](https://arxiv.org/pdf/2502.07056v1#page=1)
