# AutoGen: Enabling Next-Gen LLM Applications via Multi-Agent Conversation

**Paper:** [2308.08155](https://arxiv.org/abs/2308.08155) · [PDF](https://arxiv.org/pdf/2308.08155) · [HTML](https://arxiv.org/html/2308.08155)  
**Review status:** `fulltext_reviewed` · **Full text reviewed:** **yes**

## Research findings

**Method.** AutoGen connects models, humans and tools through a common messaging interface and programmable rules for replying and ending conversations. [PDF, p. 3](https://arxiv.org/pdf/2308.08155v2#page=3) [PDF, p. 4](https://arxiv.org/pdf/2308.08155v2#page=4) [PDF, p. 5](https://arxiv.org/pdf/2308.08155v2#page=5)

**Key result.** On the full MATH test (5,000 problems), the authors report 69.48% accuracy for AutoGen and 55.18% for GPT-4, a difference of 14.30 percentage points. A separate sample covered 120 level-5 problems. [PDF, p. 7](https://arxiv.org/pdf/2308.08155v2#page=7) [PDF, p. 20](https://arxiv.org/pdf/2308.08155v2#page=20)

**Limitations and scope.** The configurations differ in access to code execution, tools, feedback and human help. MATH measures the performance of the entire configuration. [PDF, p. 19](https://arxiv.org/pdf/2308.08155v2#page=19) [PDF, p. 20](https://arxiv.org/pdf/2308.08155v2#page=20) [PDF, p. 21](https://arxiv.org/pdf/2308.08155v2#page=21)

## Overview

The framework provides configurable agents that communicate with one another, the user and tools to complete complex tasks. [PDF, p. 1](https://arxiv.org/pdf/2308.08155v2#page=1)
