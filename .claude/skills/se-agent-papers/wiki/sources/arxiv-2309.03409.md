# Large Language Models as Optimizers

**Paper:** [2309.03409](https://arxiv.org/abs/2309.03409) · [PDF](https://arxiv.org/pdf/2309.03409) · [HTML](https://arxiv.org/html/2309.03409)  
**Review status:** `fulltext_reviewed` · **Full text reviewed:** **yes**

## Research findings

**Method.** The model generates candidates using earlier proposals and their measured scores. The study covers simple regression, traveling salesperson tours and prompt optimization for a separate executor model. [PDF, p. 3](https://arxiv.org/pdf/2309.03409v3#page=3) [PDF, p. 4](https://arxiv.org/pdf/2309.03409v3#page=4) [PDF, p. 6](https://arxiv.org/pdf/2309.03409v3#page=6) [PDF, p. 7](https://arxiv.org/pdf/2309.03409v3#page=7)

**Key result.** On GSM8K, the best instruction generated by PaLM 2-L-IT for PaLM 2-L scored 80.2%, compared with 71.8% for a manually written step-by-step reasoning instruction, a gain of 8.4 percentage points. [PDF, p. 9](https://arxiv.org/pdf/2309.03409v3#page=9)

**Limitations and scope.** The table selects the highest test score within each model pair. On the five 50-city instances, none of the three language-model optimizers found an optimal solution. [PDF, p. 6](https://arxiv.org/pdf/2309.03409v3#page=6) [PDF, p. 9](https://arxiv.org/pdf/2309.03409v3#page=9)
