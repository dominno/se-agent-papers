# MetaGPT: Meta Programming for A Multi-Agent Collaborative Framework

**Paper:** [2308.00352](https://arxiv.org/abs/2308.00352) · [PDF](https://arxiv.org/pdf/2308.00352) · [HTML](https://arxiv.org/html/2308.00352)  
**Review status:** `fulltext_reviewed` · **Full text reviewed:** **yes**

## Research findings

**Method.** MetaGPT assigns roles that pass standardized requirements, designs and implementation tasks to one another. Its feedback variant runs the code and uses the results to revise the program. [PDF, p. 4](https://arxiv.org/pdf/2308.00352v7#page=4) [PDF, p. 5](https://arxiv.org/pdf/2308.00352v7#page=5) [PDF, p. 6](https://arxiv.org/pdf/2308.00352v7#page=6)

**Key result.** With GPT-4, MetaGPT achieved 85.9% pass@1 on HumanEval and 87.7% on MBPP. Without feedback the values were 81.7% and 82.3%. [PDF, p. 7](https://arxiv.org/pdf/2308.00352v7#page=7) [PDF, p. 9](https://arxiv.org/pdf/2308.00352v7#page=9)

**Limitations and scope.** The study covered 164 HumanEval tasks, 427 MBPP tasks and the authors' SoftwareDev benchmark. Table 4 compares seven projects with human ratings on a 1–4 scale. The role ablation covers two tasks. [PDF, p. 7](https://arxiv.org/pdf/2308.00352v7#page=7) [PDF, p. 9](https://arxiv.org/pdf/2308.00352v7#page=9) [PDF, p. 24](https://arxiv.org/pdf/2308.00352v7#page=24)
