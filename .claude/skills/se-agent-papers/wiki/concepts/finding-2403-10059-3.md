# The Repoformer experiment evaluates code completion

**Reviewer’s interpretation and caveats:** RepoEval and CrossCodeLongEval measure agreement with the reference completion and, for functions, test outcomes. These evaluations provide no sample of repository repairs from which to estimate comparable gains.
