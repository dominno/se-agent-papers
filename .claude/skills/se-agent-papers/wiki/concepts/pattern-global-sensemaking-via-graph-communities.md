# Global sensemaking via graph communities

**Suggested practice:** For questions about themes across a large corpus, consider building a graph of entities and communities and synthesizing partial answers.

## Evidence

- [From Local to Global: A Graph RAG Approach to Query-Focused Summarization](../sources/arxiv-2404.16130.md)
- [Concept: graph-rag](graph-rag.md)
- [Source paper audit](../reviews/audit-2026-11-19/2404.16130v2.md)

## Limitations

The wiki editors propose this application. Its suitability for a specific setting requires a local benchmark and an assessment of the risks before adoption.
