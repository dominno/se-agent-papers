# Agent skills

Versioned instructions and procedures for recurring tasks.

**Status:** This page groups papers by topic. An entry in the list indicates **a topical relationship**. It does not imply that every claim is confirmed or that one paper cites another.

## Papers on this topic (9)

- [Evo-Harness: Context-to-Harness Skill Compilation for Self-Evolving Agents](../sources/arxiv-2608.15071.md) — The paper describes converting experience from completed tasks into reusable skills and agent configurations.
- [Evolving to Match Capabilities: Improving Harness Self-Evolution via Skill Adaptation](../sources/arxiv-2610.33024.md) — The study adapts agent skills to the capabilities of different models and compares this approach with using a single set of instructions.
- [EvoSkill: Automated Skill Discovery for Multi-Agent Systems](../sources/arxiv-2603.02766.md) — The study investigates automatic discovery, modification and evaluation of skills used by agent teams.
- [FlowEvo: Self-Evolving Agents through the Co-Evolution of Workflows and Executable Skills](../sources/arxiv-2607.21596.md) — The method improves agents' action sequences and builds executable skills for reuse.
- [How Agent Skills Evolve: A Large-Scale Empirical Study of Skills on GitHub](../sources/arxiv-2611.04456.md) — Investigates how repositories’ agent skill files change and how developers maintain them.
- [MemSkill: Learning and Evolving Memory Skills for Self-Evolving Agents](../sources/arxiv-2602.02474.md) — The study investigates how agents learn policies for storing, updating and retrieving memories.
- [MetaGPT: Meta Programming for A Multi-Agent Collaborative Framework](../sources/arxiv-2308.00352.md) — The framework organizes multiple agents through roles, standard operating procedures and documents passed between stages.
- [Socratic-SWE: Self-Evolving Coding Agents via Trace-Derived Agent Skills](../sources/arxiv-2606.07412.md) — The method uses coding-agent trajectories and failures to develop and evaluate new skills.
- [Voyager: An Open-Ended Embodied Agent with Large Language Models](../sources/arxiv-2305.16291.md) — The paper presents an agent that builds a library of executable skills and reuses them in later tasks.
