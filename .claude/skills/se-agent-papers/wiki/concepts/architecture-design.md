# Software architecture

Designing module boundaries, contracts and dependencies.

**Status:** This page groups papers by topic. An entry in the list indicates **a topical relationship**. It does not imply that every claim is confirmed or that one paper cites another.

## Papers on this topic (5)

- [Automated Design of Agentic Systems](../sources/arxiv-2408.08435.md) — The authors propose a meta-agent that automatically designs and evaluates new agent architectures.
- [Inside the Scaffold: A Source-Code Taxonomy of Coding Agent Architectures](../sources/arxiv-2604.03515.md) — The paper analyzes coding-agent frameworks and identifies common elements in their execution loops.
- [Multi-agent Architecture Search via Agentic Supernet](../sources/arxiv-2502.04180.md) — The study compares agent configurations and team sizes in terms of problem type, output quality and computational cost.
- [Retrieval-Augmented Generation for Large Language Models: A Survey](../sources/arxiv-2312.10997.md) — The survey covers basic, advanced and modular RAG, including retrieval, augmentation, generation and evaluation.
- [The OpenHands Software Agent SDK: A Composable and Extensible Foundation for Production Agents](../sources/arxiv-2511.03690.md) — The paper describes a modular toolkit for building coding agents, including adapters, a runtime and lifecycle management.
