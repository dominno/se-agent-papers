# Agent self-improvement

Evaluating and modifying agents’ instructions, skills, tools and environments.

**Status:** This page groups papers by topic. An entry in the list indicates **a topical relationship**. It does not imply that every claim is confirmed or that one paper cites another.

## Papers on this topic (22)

- [Agentic Harness Engineering: Observability-Driven Automatic Evolution of Coding-Agent Harnesses](../sources/arxiv-2604.25850.md) — The method improves the agent harness automatically using execution traces and experimental results.
- [Darwin Gödel Machine: Open-Ended Evolution of Self-Improving Agents](../sources/arxiv-2505.22954.md) — The agent edits its own code, tests variants and retains successful changes in an evolutionary archive.
- [Don't Blame the Large Language Model: How Agent Harness Evolution Shapes Coding Agent Quality](../sources/arxiv-2607.03691.md) — The study shows how changing the tools or runtime environment can alter performance while keeping the model fixed.
- [DSPy: Compiling Declarative Language Model Calls into Self-Improving Pipelines](../sources/arxiv-2310.03714.md) — The framework treats LLM programs as declarative modules whose demonstrations and instructions can be optimized against a measurable objective.
- [Evo-Harness: Context-to-Harness Skill Compilation for Self-Evolving Agents](../sources/arxiv-2608.15071.md) — The paper describes converting experience from completed tasks into reusable skills and agent configurations.
- [Evolving to Match Capabilities: Improving Harness Self-Evolution via Skill Adaptation](../sources/arxiv-2610.33024.md) — The study adapts agent skills to the capabilities of different models and compares this approach with using a single set of instructions.
- [EvoSkill: Automated Skill Discovery for Multi-Agent Systems](../sources/arxiv-2603.02766.md) — The study investigates automatic discovery, modification and evaluation of skills used by agent teams.
- [FlowEvo: Self-Evolving Agents through the Co-Evolution of Workflows and Executable Skills](../sources/arxiv-2607.21596.md) — The method improves agents' action sequences and builds executable skills for reuse.
- [From Failed Trajectories to Reliable LLM Agents: Diagnosing and Repairing Harness Flaws](../sources/arxiv-2606.06324.md) — The method analyzes failed trajectories, attributes failures to components of the agent harness and proposes targeted fixes.
- [Harness Updating Is Not Harness Benefit: Disentangling Evolution Capabilities in Self-Evolving LLM Agents](../sources/arxiv-2605.30621.md) — The study distinguishes an agent's ability to change its harness from its ability to use the resulting change effectively.
- [Harness-of-Harness: Multi-Day Autonomous Software Development with Continual Improvement](../sources/arxiv-2609.01481.md) — Studies multiday software development by agents through cycles of planning, implementation, testing and improvement.
- [How Agent Skills Evolve: A Large-Scale Empirical Study of Skills on GitHub](../sources/arxiv-2611.04456.md) — Investigates how repositories’ agent skill files change and how developers maintain them.
- [How Do Coding-Agent Harnesses Self-Evolve? An Empirical Study of Retrospective Adaptation](../sources/arxiv-2610.34938.md) — The study tests whether changes proposed after reviewing a session reduce problems on later tasks.
- [MemSkill: Learning and Evolving Memory Skills for Self-Evolving Agents](../sources/arxiv-2602.02474.md) — The study investigates how agents learn policies for storing, updating and retrieving memories.
- [Phantom Guardrails: When Self-Improving Agent Harnesses Fix Failures That Never Happened](../sources/arxiv-2607.13083.md) — The study investigates apparent security improvements made in response to problems for which there is no observational evidence.
- [Promptbreeder: Self-Referential Self-Improvement Via Prompt Evolution](../sources/arxiv-2309.16797.md) — The method evolves sets of prompts while also improving the instructions that generate new variants.
- [Reflexion: Language Agents with Verbal Reinforcement Learning](../sources/arxiv-2303.11366.md) — The method improves agent behavior through feedback and stored reflections without updating model weights.
- [Self-Authored Verification Is Unreliable in Heuristic Self-Improving Agents](../sources/arxiv-2607.24300.md) — Analyzes the risks of a self-improving agent defining the criteria used to evaluate its own changes.
- [Self-Evolving Coding Agents](../sources/arxiv-2608.03392.md) — This survey examines how coding agents improve through memory, tools, skills and collaboration.
- [Self-Evolving Coding Agents via Harness-Policy Optimization](../sources/arxiv-2610.22791.md) — The study investigates joint optimization of a coding agent's harness and policy.
- [Socratic-SWE: Self-Evolving Coding Agents via Trace-Derived Agent Skills](../sources/arxiv-2606.07412.md) — The method uses coding-agent trajectories and failures to develop and evaluate new skills.
- [Trial by Trace: Benchmarking AI Agent Harnesses for Reliability and Failure Attribution](../sources/arxiv-2610.32285.md) — The study evaluates agent infrastructure reliability and traces failures to their sources using execution traces.
