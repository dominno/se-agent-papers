# Some RAPTOR summaries contained information unsupported by the source

**Reviewer’s interpretation and caveats:** A manual check of 150 nodes from 40 stories found six summaries with hallucinations (4%). The estimate applies to the sample examined. [PDF, p. 17](https://arxiv.org/pdf/2401.18059v1#page=17) · [PDF, p. 18](https://arxiv.org/pdf/2401.18059v1#page=18)
