# Memory evaluation

Testing recall, updates and forgetting as information changes over time.

**Status:** This page groups papers by topic. An entry in the list indicates **a topical relationship**. It does not imply that every claim is confirmed or that one paper cites another.

## Papers on this topic (10)

- [A-MEM: Agentic Memory for LLM Agents](../sources/arxiv-2502.12110.md) — The memory system organizes information into a network of linked notes that it updates dynamically.
- [Agent Memory: Characterization and System Implications of Stateful Long-Horizon Workloads](../sources/arxiv-2606.06448.md) — The study characterizes the cost and access patterns of memory reads and writes in long-running agent tasks.
- [DurableFS: A File System for Persistent Memory](../sources/arxiv-1811.00757.md) — The paper describes atomic, durable file-system operations based on logging and copy-on-write.
- [Evaluating Very Long-Term Conversational Memory of LLM Agents](../sources/arxiv-2402.17753.md) — LoCoMo is a benchmark of multi-session conversations for evaluating memory and reasoning about events far apart in time.
- [Finding and Analyzing Crash-Consistency Bugs in Persistent-Memory File Systems](../sources/arxiv-2204.06066.md) — The study examines metadata persistence and recovery failures in persistent-memory file systems.
- [HippoRAG: Neurobiologically Inspired Long-Term Memory for Large Language Models](../sources/arxiv-2405.14831.md) — Knowledge graphs and Personalized PageRank support associations between facts and multi-hop retrieval.
- [LongMemEval: Benchmarking Chat Assistants on Long-Term Interactive Memory](../sources/arxiv-2410.10813.md) — The benchmark tests long-term memory, temporal reasoning, knowledge updates and appropriate abstention when information is missing.
- [Mem0: Building Production-Ready AI Agents with Scalable Long-Term Memory](../sources/arxiv-2504.19413.md) — The study analyzes how agent applications select, persist and retrieve information from long-term memory.
- [MemSkill: Learning and Evolving Memory Skills for Self-Evolving Agents](../sources/arxiv-2602.02474.md) — The study investigates how agents learn policies for storing, updating and retrieving memories.
- [SWE-MeM: Learning Adaptive Memory Management for Long-Horizon Coding Agents](../sources/arxiv-2606.28434.md) — The authors propose adaptive context and memory management for multi-stage coding tasks.
