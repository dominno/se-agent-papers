# Claim-level RAG diagnostics

**Suggested practice:** Evaluate the retriever and the generator separately by breaking answers down into individual factual claims.

- [RAGChecker: A Fine-grained Framework for Diagnosing Retrieval-Augmented Generation](../sources/arxiv-2408.08067.md)

## Limitations

The wiki editors propose this application. Its suitability for a specific setting requires a local benchmark and an assessment of the risks before adoption.
