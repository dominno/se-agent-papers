# Agent observability

Execution traces, errors, metrics and event correlation.

**Status:** This page groups papers by topic. An entry in the list indicates **a topical relationship**. It does not imply that every claim is confirmed or that one paper cites another.

## Papers on this topic (14)

- [AgentDojo: A Dynamic Environment to Evaluate Prompt Injection Attacks and Defenses for LLM Agents](../sources/arxiv-2406.13352.md) — The environment tests agents' resilience to prompt injection in external content and tool outputs.
- [Agentic Harness Engineering: Observability-Driven Automatic Evolution of Coding-Agent Harnesses](../sources/arxiv-2604.25850.md) — The method improves the agent harness automatically using execution traces and experimental results.
- [Agentless: Demystifying LLM-based Software Engineering Agents](../sources/arxiv-2407.01489.md) — The method localizes the fault, generates a patch and validates it through a simple sequence of steps.
- [AgentScope: A Flexible yet Robust Multi-Agent Platform](../sources/arxiv-2402.14034.md) — The paper presents a multi-agent platform with messaging, monitoring, fault tolerance and support for distributed execution.
- [Assessing Automated Prompt Injection Attacks in Agentic Environments](../sources/arxiv-2606.10525.md) — The study evaluates automatically generated prompt-injection attacks against tool-using agents.
- [Debugging the Debuggers: Failure-Anchored Structured Recovery for Software Engineering Agents](../sources/arxiv-2605.08717.md) — PROBE collects structured failure telemetry, diagnoses the problem and provides controlled guidance when the coding agent retries.
- [Detecting Safety Violations Across Many Agent Traces](../sources/arxiv-2604.11806.md) — The study evaluates detection of rare safety violations across collections of agent execution traces.
- [Observability and Fault Injection for LLM-Based Multi-Agent Systems in Software Engineering](../sources/arxiv-2608.24271.md) — The method combines distributed tracing of agents with controlled fault injection to diagnose reliability problems.
- [RAPTOR: Recursive Abstractive Processing for Tree-Organized Retrieval](../sources/arxiv-2401.18059.md) — The method builds a hierarchy of summaries and passages to support retrieval at multiple levels of detail.
- [Socratic-SWE: Self-Evolving Coding Agents via Trace-Derived Agent Skills](../sources/arxiv-2606.07412.md) — The method uses coding-agent trajectories and failures to develop and evaluate new skills.
- [TRACE: A Framework for Analyzing and Enhancing Stepwise Reasoning in Vision-Language Models](../sources/arxiv-2512.05943.md) — The study evaluates detection of incorrect reasoning steps and the consistency of intermediate outputs from vision-language models.
- [TRAJDEBUG: Tracing Error Lifecycle to Identify Critical Failures in Long-Horizon Agent Trajectories](../sources/arxiv-2608.06346.md) — The study follows errors through long agent trajectories and attributes failures to critical steps.
- [Trial by Trace: Benchmarking AI Agent Harnesses for Reliability and Failure Attribution](../sources/arxiv-2610.32285.md) — The study evaluates agent infrastructure reliability and traces failures to their sources using execution traces.
- [Using Process Mining to Generate AI Agents from Software Engineering Process Records](../sources/arxiv-2607.04948.md) — The authors use process mining on software-development logs to identify roles and design agents that reflect actual work.
