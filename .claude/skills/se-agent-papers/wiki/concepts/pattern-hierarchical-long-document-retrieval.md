# Hierarchical long-document retrieval

**Suggested practice:** For long documents, consider indexing passages and their recursive summaries while preserving links to the original text.

- [RAPTOR: Recursive Abstractive Processing for Tree-Organized Retrieval](../sources/arxiv-2401.18059.md)

## Limitations

The wiki editors propose this application. Its suitability for a specific setting requires a local benchmark and an assessment of the risks before adoption.
