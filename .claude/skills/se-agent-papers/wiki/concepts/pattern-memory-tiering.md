# Memory tiering

**Suggested practice:** Keep the context cache separate from long-term storage, support retrieval and track changes.

## Evidence

- [MemGPT: Towards LLMs as Operating Systems](../sources/arxiv-2310.08560.md)
- [Concept: memory-hierarchy](memory-hierarchy.md)

## Limitations

The wiki editors propose this application. Its suitability for a specific setting requires a local benchmark and an assessment of the risks before adoption.
