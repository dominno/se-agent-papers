# MemGPT distinguishes the main context from external memory

**Finding from the paper:** The main context contains instructions, editable working memory and a queue of recent messages. The model uses function calls to manage memory and retrieve selected external information. [PDF, p. 2](https://arxiv.org/pdf/2310.08560v2#page=2) · [PDF, p. 3](https://arxiv.org/pdf/2310.08560v2#page=3)
