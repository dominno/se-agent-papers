# Workflow optimization

Updating strategies and execution graphs based on task outcomes.

**Status:** This page groups papers by topic. An entry in the list indicates **a topical relationship**. It does not imply that every claim is confirmed or that one paper cites another.

## Papers on this topic (13)

- [AFlow: Automating Agentic Workflow Generation](../sources/arxiv-2410.10762.md) — The method optimizes agent workflow graphs using search and feedback from executed tasks.
- [AgentCoder: Multi-Agent-based Code Generation with Iterative Testing and Optimisation](../sources/arxiv-2312.13010.md) — AgentCoder assigns code generation, test design and test execution to separate agents in an iterative repair loop.
- [An LLM Compiler for Parallel Function Calling](../sources/arxiv-2312.04511.md) — The authors represent tool calls as a dependency graph and execute independent operations in parallel.
- [Code Generation with AlphaCodium: From Prompt Engineering to Flow Engineering](../sources/arxiv-2401.08500.md) — The authors use a multi-stage, test-driven workflow to generate and revise code in place of a single prompt.
- [DSPy: Compiling Declarative Language Model Calls into Self-Improving Pipelines](../sources/arxiv-2310.03714.md) — The framework treats LLM programs as declarative modules whose demonstrations and instructions can be optimized against a measurable objective.
- [FlowEvo: Self-Evolving Agents through the Co-Evolution of Workflows and Executable Skills](../sources/arxiv-2607.21596.md) — The method improves agents' action sequences and builds executable skills for reuse.
- [Large Language Models Are Human-Level Prompt Engineers](../sources/arxiv-2211.01910.md) — Automates instruction generation and selection by evaluating performance on test tasks.
- [Large Language Models as Optimizers](../sources/arxiv-2309.03409.md) — In OPRO, the model proposes solutions using a history of earlier candidates and their scores.
- [Promptbreeder: Self-Referential Self-Improvement Via Prompt Evolution](../sources/arxiv-2309.16797.md) — The method evolves sets of prompts while also improving the instructions that generate new variants.
- [Self-Evolving Coding Agents via Harness-Policy Optimization](../sources/arxiv-2610.22791.md) — The study investigates joint optimization of a coding agent's harness and policy.
- [Self-Refine: Iterative Refinement with Self-Feedback](../sources/arxiv-2303.17651.md) — The method iteratively generates, evaluates and revises responses while keeping model weights fixed.
- [SquirrelFS: Using the Rust Compiler to Check File-System Crash Consistency](../sources/arxiv-2406.09649.md) — The authors use Rust's type system to enforce safe ordering of file-system writes.
- [TextGrad: Automatic "Differentiation" via Text](../sources/arxiv-2406.07496.md) — The method uses textual feedback to iteratively improve components of complex AI systems.
