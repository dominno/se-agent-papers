# RAGChecker’s automated claim checks have measurable error

**Reviewer’s interpretation and caveats:** Table 16 reports 71.75% accuracy for Llama 3 as extractor and judge on noisy validation context. The result calls for validating the metric on the target data type before applying it to a new domain.
