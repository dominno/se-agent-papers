# Adding facts to the retrieval key improved some LongMemEval-M results

**Finding from the paper:** For turn-level indexing in Table 3, adding facts to the key raises Recall@5 from 0.582 to 0.644. Table 4 evaluates extracting time ranges from questions separately, with results varying by model.
