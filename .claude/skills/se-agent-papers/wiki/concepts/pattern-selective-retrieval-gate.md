# Selective retrieval gate

**Suggested practice:** Before an expensive retrieval, estimate whether new sources will add information and allow the system to skip the search.

## Evidence

- [Repoformer: Selective Retrieval for Repository-Level Code Completion](../sources/arxiv-2403.10059.md)

## Limitations

The wiki editors propose this application. Its suitability for a specific setting requires a local benchmark and an assessment of the risks before adoption.
