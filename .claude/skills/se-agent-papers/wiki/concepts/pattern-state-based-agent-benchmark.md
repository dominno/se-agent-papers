# State-based agent benchmark

**Suggested practice:** For tool-use tasks, examine changes in state and intermediate effects as well as the final text.

## Evidence

- [ToolSandbox: A Stateful, Conversational, Interactive Evaluation Benchmark for LLM Tool Use Capabilities](../sources/arxiv-2408.04682.md)
- [Concept: stateful-tool-use](stateful-tool-use.md)
- [Source paper audit](../reviews/audit-2026-11-19/2408.04682v2.md)

## Limitations

The wiki editors propose this application. Its suitability for a specific setting requires a local benchmark and an assessment of the risks before adoption.
