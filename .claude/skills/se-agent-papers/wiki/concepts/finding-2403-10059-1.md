# Repoformer learns when to add context from another file

**Finding from the paper:** The model predicts a special token that a greedy or threshold policy uses to decide whether to retrieve context. Training labels come from comparing completions generated with and without that context. [PDF, p. 3](https://arxiv.org/pdf/2403.10059v2#page=3) · [PDF, p. 4](https://arxiv.org/pdf/2403.10059v2#page=4)
