# Agent roles

Dividing responsibilities, permissions and specialties among independent participants.

**Status:** This page groups papers by topic. An entry in the list indicates **a topical relationship**. It does not imply that every claim is confirmed or that one paper cites another.

## Papers on this topic (5)

- [CAMEL: Communicative Agents for "Mind" Exploration of Large Language Model Society](../sources/arxiv-2303.17760.md) — The study explores autonomous agent collaboration through role-playing and prompts that keep it aligned with human goals.
- [ChatDev: Communicative Agents for Software Development](../sources/arxiv-2307.07924.md) — The study describes software development by agents with different roles working together through structured conversations.
- [CodeTeam: An LLM-Powered Multi-Agent Framework for Repository-Level Code Generation](../sources/arxiv-2606.22082.md) — The paper describes a team of agents that builds complete repositories from architectural plans and contracts.
- [MetaGPT: Meta Programming for A Multi-Agent Collaborative Framework](../sources/arxiv-2308.00352.md) — The framework organizes multiple agents through roles, standard operating procedures and documents passed between stages.
- [Prometheus 2: An Open Source Language Model Specialized in Evaluating Other Language Models](../sources/arxiv-2405.01535.md) — The authors present an open judge model for absolute scoring and pairwise comparisons using user-defined criteria.
