# The DSPy compiler uses a metric to select demonstrations

**Finding from the paper:** In the bootstrap variant, the compiler runs a teacher program, keeps traces that meet the metric and assigns demonstrations to the corresponding modules. The search variant compares sets of demonstrations. [PDF, p. 6](https://arxiv.org/pdf/2310.03714v1#page=6) · [PDF, p. 28](https://arxiv.org/pdf/2310.03714v1#page=28)
