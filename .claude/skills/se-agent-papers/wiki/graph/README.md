# Knowledge graph metadata

In the 20 November 2026 audit, `nodes.jsonl` contained 255 publication, concept, and entity nodes. `edges.jsonl` contained 996 edges.

| Edge | Interpretation |
|---|---|
| `about_topic` | Topic assigned automatically from a paper title or catalog entry |
| `described_by` | A named method and the paper that describes it |
| `compared_thematically` | An editorial comparison between related topics |

These edges support navigation. Verified citations and experimental evidence require a separate check against the paper.
